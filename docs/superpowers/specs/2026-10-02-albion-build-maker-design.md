# Albion Build Maker — дизайн

Дата: 2026-10-02. Статус: на согласовании.

## Цель

Сайт, где игрок Albion Online собирает билд: для каждого слота выбирает вещь,
тир, зачарование, качество и навыки на ней, а затем получает картинку сета
(PNG), которую можно вставить куда угодно (Discord, форум, гайд), и ссылку,
по которой открывается тот же билд.

Успех: билд из 10 слотов с навыками собирается меньше чем за минуту,
нужная вещь находится поиском с 2–4 букв, PNG скачивается и копируется
в буфер в Chrome, Safari и Firefox.

## Решения, принятые с пользователем

- Отдельный сайт, свой репозиторий `albion-build-maker`, GitHub Pages.
- «Поиск» = быстрый поиск вещей и навыков внутри конструктора. Каталога
  чужих билдов и SEO-страниц на старте нет.
- Картинка компактная, в духе окна экипировки в игре.
- Иконки хранятся в репозитории (render.albiononline.com не отдаёт CORS,
  поэтому его картинки нельзя рисовать на canvas для экспорта).

## Вне рамок (YAGNI)

Сервер, аккаунты, каталог билдов, цены сета, расчёт характеристик
(IP, урон, сопротивления), артефактные варианты сверх того, что есть в дампе
как отдельные вещи, скины маунтов.

## Источники данных

`ao-data/ao-bin-dumps` (master):

- `items.json` — вещи. Слоты: `equipmentitem.@slottype` ∈ head, armor,
  shoes, cape, offhand, bag, mainhand; оружие в `weapon` (`@twohanded`
  блокирует offhand); маунты в `mount`; еда и зелья в `consumableitem`.
- Навыки вещи: `craftingspelllist`. Если есть `@reference`, берётся список
  указанной вещи (рекурсивно), затем применяются `removespell` и
  `craftspell` текущей. У `craftspell.@slots`: 1 = Q, 2 = W, 3 = E,
  у брони, шапки и обуви активный навык один — в игре это R (броня),
  D (шапка), F (обувь); без `@slots` — пассивка.
- `spells.json` — `activespell`, `passivespell`, `togglespell`.
- `formatted/items.json` — локализованные названия вещей;
  `localization.json` — названия навыков (по `@namelocatag`).
- Иконки: `render.albiononline.com/v1/item/<ID>.png` и
  `/v1/spell/<UNIQUENAME>.png` — только при сборке, не в рантайме.

Берём только вещи T4–T8 (плюс маунты и расходники всех тиров), которые
можно надеть; служебные/тестовые/квестовые отсекаются фильтром по
`@shopcategory` и наличию в formatted/items.json.

## Устройство

```
albion-build-maker/
  index.html          разметка + стили
  js/app.js           состояние билда, URL-хэш, localStorage
  js/picker.js        окно выбора вещи с поиском
  js/search.js        нормализация и ранжирование поиска (чистые функции)
  js/render.js        отрисовка PNG на canvas
  js/codec.js         билд <-> строка для хэша (чистые функции)
  js/i18n.js          ru/en интерфейс
  data/items.json     компактный справочник (генерируется)
  data/spells.json    компактный справочник навыков (генерируется)
  icons/items/*.webp  по одной иконке на базовую вещь, 128px
  icons/spells/*.webp иконки навыков, 64px
  tools/fetch.mjs     сборка data/ и icons/ из дампов
  tools/check.mjs     проверка целостности данных
  test/*.test.mjs     тесты чистых модулей (node --test)
```

Без фреймворков и сборщика, как основной сайт. Node только для `tools/`
и тестов.

### Формат data/items.json

```json
{ "v": "<дата дампа>",
  "items": [{ "id": "2H_CLAYMORE", "slot": "mainhand", "two": true,
              "tiers": [4,5,6,7,8], "ench": 4,
              "n": { "RU-RU": "Клеймор", "EN-US": "Claymore", ... },
              "spells": { "q": ["HEROICSTRIKE2","CLEAVE"], "w": [...],
                          "e": [...], "p": [...] } }] }
```

`id` без тира: вещь одна для всех тиров, тир — выбор пользователя.
Названия хранятся без префикса тира («Клеймор знатока» → «Клеймор»).
Набор навыков у разных тиров одной вещи совпадает — `check.mjs` это
проверяет и падает, если нет.

### Иконки

Иконка на каждый тир вещи (без зачарования), WebP 128px — тир уже вшит
в иконку render. Зачарование и качество рисуем сами:

- тир — римская цифра в левом верхнем углу (IV–VIII);
- зачарование — «.1»–«.4» рядом с тиром, цвет: зелёный, синий,
  фиолетовый, золотой;
- качество — цвет рамки: обычное без рамки, хорошее серая,
  выдающееся бронзовая, отличное серебряная, шедевр золотая.

Ожидаемый объём: ~1500 вещей × ~15 КБ + ~1000 навыков × ~5 КБ ≈ 25–30 МБ.

## Интерфейс

- Верх: поле «Название билда», язык ru/en.
- Сетка слотов как в игре: сумка — шапка — плащ / основное оружие —
  броня — второе оружие / зелье — обувь — еда, маунт отдельно.
  Двуручное оружие гасит второе оружие.
- Клик по слоту → окно выбора: поле поиска в фокусе, список вещей этого
  слота, фильтр по категории (меч, топор…). Под списком — тир (4–8),
  зачарование (0–4), качество (1–5); последние значения запоминаются.
- После выбора вещи рядом со слотом — ряды навыков (Q/W/E или R/D/F плюс пассивка),
  клик выбирает навык, по умолчанию первый в списке.
- Справа живое превью картинки, под ним «Скачать PNG», «Копировать
  картинку», «Копировать ссылку».

### Поиск

Нормализация: нижний регистр, ё→е, без диакритики и пунктуации.
Ищет по названиям на всех языках дампа и по `id`. Ранг: начало
названия > начало слова > подстрока. Без задержки, на каждый ввод.
Пустой запрос — все вещи слота, сгруппированные по категории.

## Картинка (render.js)

Canvas 2× плотности. Фон тёмный, в духе игрового интерфейса. Сверху
название билда. Слоты той же раскладкой, что на странице; у оружия, брони,
шапки и обуви справа иконки выбранных навыков с подписями Q/W/E (оружие), R (броня), D (шапка), F (обувь), пассивки
 — без буквы, в круглой рамке.
Внизу мелко адрес сайта. «Копировать» — `navigator.clipboard.write` с
`ClipboardItem`; если браузер не умеет — кнопка скрыта, остаётся скачивание.
Шрифт системный — без внешних запросов.

## Текст билда (text.js)

Добавлено по просьбе пользователя 2026-10-02: под конструктором поле с текстом
сета по слотам в игровом порядке — «Оружие: Клеймор 8.3, шедевр — Q: …, E: …,
пассивка: …», «Голова: …», «Еда: …» — и кнопка «Копировать текст».
Язык интерфейса по умолчанию — русский. Слоты и навыки стоят по центру,
под ними текст и картинка.

## Ссылка (codec.js)

Билд кодируется в `#b=<строка>`: версия формата, название, для каждого
слота id, тир, зачарование, качество и коды навыков (переживают смену порядка в патче). JSON → UTF-8 →
base64url. Неизвестный id или битая строка — слот пустой, остальное
загружается, вверху короткое предупреждение. Последний билд в localStorage
(обёрнут в try/catch).

## Ошибки

- `data/*.json` не загрузился → сообщение с кнопкой «Повторить».
- Нет иконки → серый квадрат с кодом вещи; в PNG то же.
- Навык из ссылки не входит в список вещи → берётся первый доступный.

## Проверка

- `node --test`: codec (туда-обратно, битые строки, старая версия),
  search (ё/е, языки, ранжирование), сборка списка навыков из
  `@reference` + `removespell` (на фикстуре Клеймора: E-слот =
  CLAYMORECHARGE, MIGHTYBLOW удалён).
- `tools/check.mjs`: у каждой вещи и навыка есть иконка, у каждой вещи
  ≥1 навык в каждом из её слотов, нет дублей id.
- В браузере: собрать 2 билда (двуручный ганк, одноручный с щитом),
  скачать PNG, открыть по ссылке в новой вкладке, проверить на ширине
  телефона.

## Обновление после патчей

`node tools/fetch.mjs` → `node tools/check.mjs` → коммит. Скачивает
только недостающие иконки.
